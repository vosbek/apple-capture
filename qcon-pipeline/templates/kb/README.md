## How to read this repo

- `actions.md`: every suggested first step from every talk, in one table. Start here.
- `talks/<date>/<talk_id>.md`: one brief per talk, reviewed before publishing.
- `themes/`: ideas that came up in three or more talks.
- `speakers/`: public facts about speakers, with sources.
- `SOURCES.md`: how claims are marked, and what the marks mean.

Official session videos are for registered attendees only (QCon login, streaming, from Dec 21, 2026).
This repo links to them and never stores them.
